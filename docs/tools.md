## math (v1.0.0)

### `math.percentage`

Calculates what percentage `part` is of `whole`: part / whole * 100.

- **Use when:** "what percent of 250 is 40?"; share of a total expressed in percent
- **Do not use when:** you need X percent of a value (use math.percentage_of); you need growth between two values (use math.percentage_change)
- **Limitations:** whole must be non-zero

| Parameter | Required | Description |
| --- | --- | --- |
| `part` | yes | The part value. |
| `whole` | yes | The total value (denominator). Must be non-zero. |

Example input: `{"part":40,"whole":250}`

### `math.percentage_of`

Calculates `percent` percent of `value`: value * percent / 100.

- **Use when:** "what is 15% of 80?"; tips, discounts or tax amounts given a percent rate
- **Do not use when:** you need which percent one number is of another (use math.percentage)

| Parameter | Required | Description |
| --- | --- | --- |
| `percent` | yes | Percent to take, e.g. 15 for 15%. |
| `value` | yes | The base value. |

Example input: `{"percent":15,"value":80}`

### `math.percentage_change`

Calculates relative change from oldValue to newValue in percent: (newValue - oldValue) / |oldValue| * 100.

- **Use when:** growth or decline between two values; "price went from 50 to 75, what is the change in %?"
- **Do not use when:** percentage points difference between two percentages (subtract them directly)
- **Limitations:** oldValue must be non-zero; divides by |oldValue| so that a change from a negative base toward zero is reported as an increase

| Parameter | Required | Description |
| --- | --- | --- |
| `oldValue` | yes | Original (reference) value. Must be non-zero. |
| `newValue` | yes | New value. |

Example input: `{"oldValue":50,"newValue":75}`

### `math.ratio`

Calculates the ratio a:b as a quotient (a / b) and as a reduced integer ratio when possible.

- **Use when:** "what is the ratio of 1920 to 1080?"; simplify a ratio like 150:100 to 3:2
- **Do not use when:** solving for a missing term of a proportion (use math.proportion)
- **Limitations:** b must be non-zero; reduced ratio is only produced for inputs with at most 10 decimal places

| Parameter | Required | Description |
| --- | --- | --- |
| `a` | yes | First term (antecedent). |
| `b` | yes | Second term (consequent). Must be non-zero. |

Example input: `{"a":1920,"b":1080}`

### `math.proportion`

Solves the proportion a / b = c / d for the single missing term. Provide exactly three of a, b, c, d; omit the unknown one.

- **Use when:** rule of three: "3 apples cost 4.50, how much do 7 cost?" -> a=3, b=4.5, c=7, solve d; scaling recipes or maps with a fixed ratio
- **Do not use when:** inverse proportionality (x * y = const); just dividing two numbers (use math.ratio)
- **Limitations:** exactly one term must be omitted; terms used as denominators in the solved form must be non-zero

| Parameter | Required | Description |
| --- | --- | --- |
| `a` | no | Numerator of the left fraction. |
| `b` | no | Denominator of the left fraction. |
| `c` | no | Numerator of the right fraction. |
| `d` | no | Denominator of the right fraction. |

Example input: `{"a":3,"b":4.5,"c":7}`

### `math.round`

### `finance.compound_interest`

Future value and interest earned on a single deposit with compound interest: FV = principal * (1 + i)^(compoundingPerYear * years).

- **Use when:** "how much will 10,000 grow to at 5% compounded monthly over 10 years?"; interest earned on savings
- **Do not use when:** regular deposits or payments (use finance.annuity_future_value); interest without compounding (use finance.simple_interest)
- **Limitations:** annualRatePercent is in percent (5 = 5%); fractional periods (e.g. 1.5 years with annual compounding) are compounded exponentially; intermediate values keep 34 significant digits; only final results are rounded to `scale` with `roundingMode`; no day-count convention is applied: time is measured in years and periods

| Parameter | Required | Description |
| --- | --- | --- |
| `principal` | yes | Initial deposit. Number or exact decimal string. Positive magnitude. |
| `annualRatePercent` | yes | Annual interest rate in PERCENT (5 means 5%, not 0.05). Must be greater than -100. |
| `rateType` | yes | Required. "nominal": annual rate r is split evenly across compounding periods (r / compoundingPerYear, like APR). "effective": annual rate already includes compounding (like APY/AER); the result does not depend on compoundingPerYear. |
| `compoundingPerYear` | yes | Required. Compounding periods per year: 1 annual, 2 semiannual, 4 quarterly, 12 monthly, 52 weekly, 365 daily. |
| `years` | yes | Duration in years (may be fractional, e.g. 1.5). |
| `scale` | no | Decimal places of monetary results. Default 2. Use 0 for currencies without minor units (JPY). |
| `roundingMode` | no | Rounding mode applied only to final results. Default half_up (half away from zero, like Excel ROUND). |
| `currency` | no | Optional ISO 4217 currency code. Adds `currency` and a `formatted` string to the output. |

Example input: `{"principal":10000,"annualRatePercent":5,"rateType":"nominal","compoundingPerYear":12,"years":10}`

### `finance.npv`

Net present value of equally spaced signed cash flows at a periodic discount rate. Whether cashFlows[0] occurs now (undiscounted) or at the end of the first period must be stated explicitly.

- **Use when:** evaluating an investment with an initial outlay and future returns; discounting irregular amounts at equal intervals
- **Do not use when:** equal payments (use finance.annuity_present_value); finding the break-even rate (use finance.irr)
- **Limitations:** cash flows are signed: negative values are outflows (investments), positive values are inflows; cash flows must be equally spaced; the rate is per spacing period (use a monthly rate for monthly flows); firstCashFlowAt "now": NPV = sum CF[k] / (1+r)^k (cashFlows[0] undiscounted, the usual textbook/finance convention); firstCashFlowAt "end_of_first_period": NPV = sum CF[k] / (1+r)^(k+1) (Excel NPV() convention); ratePercent is the rate per period in percent (10 = 10%); intermediate values keep 34 significant digits; only final results are rounded to `scale` with `roundingMode`

| Parameter | Required | Description |
| --- | --- | --- |
| `ratePercent` | yes | Discount rate per period in PERCENT (10 means 10%). |

### `finance.irr`

Internal rate of return of equally spaced signed cash flows: the periodic rate at which NPV (with cashFlows[0] at time 0) equals zero.

- **Use when:** return of an investment with an initial outlay and later inflows; Excel IRR() equivalent
- **Do not use when:** cash flows at irregular dates (not supported; XIRR is out of scope); you already know the rate and need value (use finance.npv)
- **Limitations:** cash flows are signed: negative values are outflows (investments), positive values are inflows; cash flows must be equally spaced; the rate is per spacing period (use a monthly rate for monthly flows); cashFlows[0] is at time 0; the result is the rate per spacing period in percent; pass periodsPerYear to also get the effective annual rate; requires at least one negative and one positive cash flow (UNSUPPORTED_OPERATION otherwise); searches rates between -99.99% and 10000% per period on a fixed grid, then refines each bracket with safeguarded Newton iteration (bisection fallback); cash flows with several sign changes can have several IRRs: all found roots are returned in `solutions` and `result` is the one closest to 0

| Parameter | Required | Description |
| --- | --- | --- |
| `cashFlows` | yes | Signed cash flows at equally spaced periods, in chronological order (max 1000). Negative = outflow, positive = inflow. Numbers or exact decimal strings. |
| `periodsPerYear` | no | Optional. Periods per year of the cash-flow spacing (12 for monthly) to compute the effective annual rate. |
| `decimals` | no | Decimal places of percentage results. Default 6. |

Example input: `{"cashFlows":[-70000,12000,15000,18000,21000,26000]}`

## datetime (v1.0.0)

### `datetime.date_difference`

Difference from `start` to `end` in calendar days and weeks, as a years/months/days breakdown, and (for two date-times) exact elapsed time.

- **Use when:** "how many days between 2026-01-15 and 2026-03-01?"; age or tenure in years, months and days; elapsed hours between two timestamps
- **Do not use when:** working days only (use datetime.business_days_between)
- **Limitations:** result is negative when end is before start; days counts calendar-date boundaries: end date minus start date (the start day is not counted); years/months/days breakdown adds whole months from start with end-of-month clamping (Jan 31 + 1 month = Feb 28/29); the machine time zone is never used; date-times must carry an offset (Z, +02:00) and IANA time zones must be given explicitly; there is no implicit "today": pass the current date explicitly if needed

| Parameter | Required | Description |
| --- | --- | --- |
| `start` | yes | Start date. Format YYYY-MM-DD, or ISO 8601 date-time with offset (2026-03-15T09:30:00+01:00 / ...Z). |
| `end` | yes | End date. Format YYYY-MM-DD, or ISO 8601 date-time with offset (2026-03-15T09:30:00+01:00 / ...Z). |
| `timeZone` | no | Optional IANA time zone (e.g. "Europe/Berlin"). Used to interpret date-time inputs as local wall-clock time. |

Example input: `{"start":"2024-01-31","end":"2025-03-01"}`

### `datetime.add_days`

Adds (or subtracts, with a negative number) calendar days to a date. For date-times the wall-clock time is preserved, including across DST changes when timeZone is given.

- **Do not use when:** working days (use datetime.add_business_days)
- **Limitations:** with timeZone, a wall-clock time that does not exist (DST gap) moves forward by the gap; an ambiguous time (DST overlap) resolves to the earlier instant; without timeZone, date-times keep their original fixed offset; the machine time zone is never used; date-times must carry an offset (Z, +02:00) and IANA time zones must be given explicitly; there is no implicit "today": pass the current date explicitly if needed

| Parameter | Required | Description |

| `timeZone` | no | Optional IANA time zone (e.g. "Europe/Berlin"). Used to interpret date-time inputs as local wall-clock time. |

Moves a date forward (or backward, with a negative number) by a number of business days, skipping weekends and the given holidays. Same semantics as Excel WORKDAY.

## units (v1.0.0)

| `to` | yes | Target unit symbol or name. |
